# 📅 Interactive Calendar

A simple and interactive calendar web application designed to help users view dates, navigate between months, and organize their daily schedules. Features a clean interface for convenient date tracking and planning.

## ✨ Features

- Display current month and year
- Navigate between previous and next months
- Highlight the current date
- View dates in a structured calendar layout
- Interactive calendar navigation
- Clean and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Interactive-Calendar.git
```

### 2. Navigate to the project folder

```bash
cd Interactive-Calendar
```

### 3. Run the application

Open the HTML file in your web browser.

## 📸 Preview

Launch the application locally to explore the interactive calendar.
